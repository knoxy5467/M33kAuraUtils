# GroundAuraTracker Changelog

## v1.0.0 (Initial Release)
- Initial release of GroundAuraTracker.
- Dual-state tracking engine for ground-placed effects (lifetime duration + in-zone buff).
- Built-in presets for Paladin (*Consecration*), Death Knight (*Death and Decay*, *Defile*), Druid (*Efflorescence*), Shaman (*Healing Rain*), Demon Hunter (*Sigil of Flame*).
- Support for custom user-registered ground spells.
- Standalone movable UI frame with timer text, status bar, and green/red/dimmed color feedback.
- Cross-addon injection for ThisWeeksAuras / WeakAuras.
- 100% native Lua unit test suite with 83 automated test cases.
